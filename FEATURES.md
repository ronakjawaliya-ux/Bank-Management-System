# 🚀 Bank Management System - Features

## 👤 Account Management

- Create new bank accounts
- View all registered accounts
- Search account by Account ID
- Update customer details
- Delete existing accounts
- Prevent duplicate Account IDs

---

## 💰 Banking Operations

- Deposit money
- Withdraw money
- Transfer money between accounts
- Check account balance
- Calculate total money in the bank

---

## 💾 Data Storage

- JSON-based data storage
- Automatic save after every operation
- Automatic data loading when the program starts

---

## ✅ Input Validation

- Positive Account ID validation
- Duplicate Account ID prevention
- Name validation
- Age validation
- Phone number validation
- Balance validation
- Deposit amount validation
- Withdrawal amount validation
- Transfer amount validation

---

## ⚠️ Error Handling

- Handles invalid numeric inputs
- Handles missing account records
- Handles missing JSON file
- Handles corrupted JSON file
- Handles file saving errors

---

## 📊 Statistics

- Total number of bank accounts
- Total money available in the bank
